# 隐私与诊断说明

## 本机配置

应用枚举当前用户已安装的应用名称、包名和图标，供用户选择生效范围。总开关、全局模式、等待识别档位及所选包名保存在 MODE_PRIVATE SharedPreferences。没有把用户已安装应用清单作为源码样例发布。

配置 Provider 是只读接口，外部读取要求 Android 的特权 DUMP 权限。系统进程根据本机前台包名决定是否生效，并取消跨应用迟到的结果。

## 人脸与日志

模块读取原生 AON 内存中的脸角度、检测状态、图像方向和同帧手机方向。未实现人脸图像保存、图像上传或其他网络上传。

运行日志可能包含方向角、检测数量、识别/绑定状态和错误堆栈。DUMP 权限诊断状态还会返回并记录当前前台应用包名。日志并不等于没有敏感信息，分享前应逐项检查。

不要向公开 issue 上传未经处理的完整日志、应用列表、系统转储、个人截图或签名密钥。

本模块没有声明 INTERNET 权限，但钩子也运行在系统和厂商进程中；“没有上传代码”是对本模块源码的描述，不代表厂商 AON 或 ROM 已经过隐私审计。

## 特权诊断

TEST 可注入合成输入或触发真实识别。PROBE 可独立请求约5秒真实识别，调试路径不检查普通界面的开关或应用范围。两者都要求 DUMP 权限。

REPLAY 的几何和角度为合成测试数据，不读取真实图像，不打开相机。它会在 AON 的应用缓存中保存文本报告，并写入 Xposed 日志；报告不会自动删除。代码只使用应用的 getCacheDir，不保证所有 ROM 的缓存具体存储位置。

## 发布文件边界

公开文件只包括源代码、图标和文档。真实设备报告、截图、日志、数据库、用户配置、设备标识、签名密钥和反编译的厂商文件均未纳入仓库。构建所需的官方 Xposed API 由构建脚本下载并验证，作为编译依赖而非随仓库分发。
