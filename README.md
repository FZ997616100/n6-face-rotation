# 智感旋转 · N6 Face Rotation

<img src="docs/assets/launcher-icon.svg" width="112" alt="智感旋转图标">

**[下载安装包 v0.4.9](https://github.com/FZ997616100/n6-face-rotation/releases/download/v0.4.9/n6-face-rotation-v0.4.9.apk)** · [版本发布页](https://github.com/FZ997616100/n6-face-rotation/releases/tag/v0.4.9)

在手机转动时，短时调用 OPPO 原生 AON 低功耗人脸方向识别，让屏幕方向适应你与手机的相对姿势。

**这是一个带设置界面的 LSPosed 模块 APK，需要 Root 和 LSPosed。单独安装到普通未修改的手机上不会生效。**

当前验证环境：OPPO Find N6，ColorOS 17 / Android 17。依赖厂商私有接口，不保证其他 OPPO、一加、realme 或其他系统版本可用。

## 旋转规则

应用明确指定横屏、竖屏、跟随下层页面或锁定方向时，由系统处理，模块不会覆盖。例如视频点全屏时进入横屏、退出全屏时恢复应用要求的方向。应用切换方向时先采用系统结果作为新基准，切换前的识别结果不再生效；限定方向的页面不发起新的人脸识别。

下表适用于未限定横竖方向的页面：

| 识别结果 | 系统自动旋转 | 行为 |
| --- | --- | --- |
| 识别到有效人脸方向 | 开或关 | 按人脸相对手机的方向旋转，模块优先 |
| 没有识别到人脸、超时或接口失败 | 开 | 交回系统正常自动旋转规则 |
| 没有识别到人脸、超时或接口失败 | 关 | 保持当前实际屏幕方向，不退回旧锁定方向 |

自动旋转关闭时，无脸保持以此刻实际显示方向为基准；之后开启自动旋转即交回系统。此保持只在模块生效范围内，关闭模块、离开所选应用或锁屏后恢复系统原有策略。模块不改写系统自动旋转开关或保存的锁定方向，也不把“无脸”当成0度。

## 安装和设置

1. 下载并安装发布页中的 APK（也可自行构建），在 LSPosed 中启用“智感旋转”。
2. 作用域选择 **系统框架** 和 **AONService（com.aiunit.aon）**，然后重启手机。
3. 打开智感旋转，开启总开关；选择“全局”或勾选需要生效的应用。

需要控制的应用在智感旋转的界面中选择，不需要逐个加到 LSPosed 作用域。全局与所选应用切换会保留勾选；总开关关闭表示停用本模块。

旧 API 的推荐数组使用 `android`。已验证的 LSPosed IT 7906 将其映射为实际“系统框架/system”；不要把包名为 `android` 的另一项“Android 系统”误当成本机的系统框架目标。APK 同时包含设置界面和钩子逻辑，不需要另装一个配套 APK。

## 触发与功耗

亮屏且解锁、处于允许范围时，使用 TYPE27 的 on-change 方向事件。方向变化稳定约150毫秒后发起一次短时 AON 请求；正常请求的结果等待窗口约800毫秒，有效结果可以提前结束。首次服务绑定另有等待期限。

静止时不循环发起人脸识别。锁屏、关屏、关闭总开关或离开所选应用时，注销本模块监听、取消当前请求并解绑。正常使用期间服务绑定可以保持温热连接；绑定存在不等于一直采集相机。原生服务可能延迟关闭硬件，800毫秒不是物理断电承诺。尚未测量电池百分比或功率消耗。

## 从源码构建

需要 Python 3.9+、JDK17、Android SDK platform36 和 build-tools36.0.0。设置 `JAVA_HOME` 与 `ANDROID_SDK_ROOT`，在仓库根目录运行：

```sh
python module/build.py
```

也可用 `--sdk` 指定 SDK，`--xposed-api` 指定 Xposed API82 JAR。未提供 JAR 时，脚本从官方 Maven 地址下载并验证固定 SHA-256；API 仅作为编译依赖，不进入 APK。参考 [Xposed API 使用说明](https://github.com/rovo89/XposedBridge/wiki/Using-the-Xposed-Framework-API)。

构建输出位于 `outputs/`。首次本地构建会在 `work/module-signing/` 生成调试签名；签名目录不会进入版本控制。不同构建者生成的密钥不同，覆盖更新已有 APK 时需要保持同一签名。

## 开发诊断

保留了需要 `android.permission.DUMP` 的显式诊断广播；普通应用不能随意调用。

- `TEST`：返回控制器状态；可以注入合成角度，`real=true` 使用真实短时 AON 请求。
- `PROBE`：仅在厂商 AON UI 进程中注册，可独立启动约5秒真实识别，不受普通界面开关/应用范围的约束，仅供特权排查。
- `REPLAY`：执行合成输入回放，不打开相机；报告写入 AON 应用自己的缓存，代码不会自动删除报告。
